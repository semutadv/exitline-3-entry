# Effective Immediately, Unlike the Printer

A one-line resignation letter: the sender quits effective immediately
— unlike the printer they were hired to fix in 2019, which has
outlived three CEOs and the sender's entire will to live. Six years of
service, summarised as a comparison with office equipment.

The program clears the contents of the output directory and writes the
line to `entry.txt`, byte for byte, with no trailing newline.
